**Is this detectable?**  
Rockstar actively bans accounts caught using mod menus — external ones included . Use at your own risk, ideally never on an account you care about. [citation:6][citation:11]

**Does it work on GTA Online?**  
Yes — it's built for GTA Online with money tools, protection options, and session management .

**What is Modest Menu?**  
Modest Menu is the official name of Kiddions Mod Menu — an external tool with a plain grey interface, no flashy visuals . [citation:5][citation:6]

**What is Lua scripting?**  
You can add community-made custom scripts to the menu — max vehicle mods, max abilities, kill all enemies, and more . [citation:2][citation:4][citation:9]
